" README SUMMARY" - Shake Table Model for Seismic performance in the elevator guide rails

Project Purpose:
This project analyses the seismic performance results (inter-storey drift ratios, friction connection drift, and structure velocity)
obtained from shake table physical tests and numerical modelling tests.

Key Features of Both Models
1. Friction connection sliding
2. Inter-storey drift ratio
3. Absolute Velocity


Input File issues (Physical Test Lasers Data):
1. Imported trial 1 to trial 3 files are "2.10_1nd floor_trial_1 to 2.10_1nd floor_trial_3".
2. Imported trial 4 file is messy, not use it.
3. Imported trail 5 to trial 7 files are " 2.10_2nd floor_trial_1 to 2.10_2nd floor_trial_3" .


Outputs:
1. Maximum absolute values (
    Peak friction connection sliding (mm),
    peak floor velocity (m/s),
    and maximum drift ratio (%) for all storeys.
    )

2. Time-history plots of displacements(
    Corrected horizontal elevator sliding vs time,
    Inter-storey drift ratio vs time (physical data),
    Friction connection sliding vs time(numerical data)
    )
